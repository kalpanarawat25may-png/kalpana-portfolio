# Kalpana Rawat — Personal Portfolio

A responsive, single-page portfolio website built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser.

## Before publishing
1. Replace `your-email@example.com` in `index.html` with your preferred contact email.
2. Add your college name, university and graduation year in the Education section.
3. Update the skill descriptions and add real projects as you complete them.
4. Add your LinkedIn profile URL if you want it displayed.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub named `kalpana-portfolio`.
2. Upload all files and folders from this project (keep `index.html` in the repository root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. After GitHub finishes publishing, your site will be available at:
   `https://kalpanarawat25may-png.github.io/kalpana-portfolio/`

## Files
- `index.html` — page content
- `style.css` — layout, colors and responsive styling
- `script.js` — mobile menu and reveal effects
- `assets/profile.jpg` — your supplied profile photo
